# Katkı

pixelBrain'e katkıya açığız: hata bildirimi, fikir, belge ya da kod.

- **Hata ve fikir:** [issue aç](https://github.com/berkaysirtas/pixelBrain/issues/new/choose); formdaki alanlar yeterli.
- **Kod:** küçük ve tek konulu bir pull request gönder. Değişikliğin neyi çözdüğünü ve nasıl sınadığını yaz.

## Çalıştırma ve sınama

```sh
sh kur.sh                         # eksikleri tamamlar
./baslat.sh                       # http://127.0.0.1:4700
python3 araclar/guncelle-sinama.py
sh araclar/tum-duman.sh           # sunucu açıkken, tarayıcıyla duman sınamaları
```

Sunucu yalnız Python standart kütüphanesiyle çalışır; yeni bağımlılık eklemeden önce bir issue'da konuşalım. Arayüz metinleri
Türkçe. Şema ve tasarım kararları `BEYIN.md`, pano biçimi `PANO.md` içinde.

## Lisans

Katkın [pixelBrain Lisansı](LICENSE) ile birlikte kabul edilir (Part I, 2. madde): üretici lisansı daha sıkı ya da daha
gevşek hâle getirebilir ve katkın ticari amaçla kullanılabilir. Pull request göndererek bunu kabul etmiş olursun.
